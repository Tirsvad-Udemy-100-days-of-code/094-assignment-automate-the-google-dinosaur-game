## What was done

The plan before any code: Business Case BC-001, Stakeholder Analysis SA-001, Project Plan PP-001 and six milestones, each reviewed with a `Go` record. The repository got its description and topics on the git host.

## What was gained

- Success criteria with numbers (a score of 1000, 90 % coverage) turn "make it work" into something that can be checked.
- One branch and one pull request per milestone keeps every step small and easy to review.
- Deciding early that no test may drive the real desktop shaped the whole design: the bot talks to the screen and keyboard only through small interfaces.
